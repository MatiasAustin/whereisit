# WhereIsIt? — Jakarta & Kab. Karawang 3D Design Studio

**Transforms personal data, achievements, and everyday routines into meaningful physical products.**

*Personal data. Physical products. Meaningful experiences.*

## Struktur Produk Resmi

1. **Pre-Order Tersedia (Mayar Checkout + Post-Payment Data Flow):**
   - `/preorder/keychain-strava`: **Keychain Custom Data Strava x Where Is It? 3D print Custom** (`10x5 cm` Rp119.000, `10x5 cm Emoney` Rp150.000, `10x5 cm Flazz` Rp200.000).
   - `/preorder/keychain-strava/data`: Form data Strava wajib setelah pembayaran (URL Strava + 1-3 screenshot rute).
   - `/track`: Pelacakan status PO 9 tahap & Live Queue publik.

2. **Coming Soon (Teaser + Notify List):**
   - `/strava-route-lamp`: **Personalized Strava Route Lamp** (Coming Soon).
   - `/smart-cube`: **Smart Cube — Strava Cube Display** (Dalam pengembangan — belum bisa dipesan).

3. **Admin Dashboard (`/admin/orders`):**
   - Manajemen antrian PO Strava, pengaturan lead time produksi, serta daftar minat produk Coming Soon (`Minat Lamp`, `Minat Cube`, `Minat Lineup Lainnya`).
